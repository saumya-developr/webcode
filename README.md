## 🚀 How to Run Locally

If you want to clone this repository and test the website on your local machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the project folder:**
   ```bash
   cd YOUR_REPO_NAME
   ```
3. **Open the project:**
   Simply open the main `index.html` file in any web browser.
